# To-Do лист

Приложение для управления задачами с авторизацией и сохранением в localStorage.

**Сайт:** [todo-task-ak.netlify.app](https://todo-task-ak.netlify.app)

---

## Функционал

- Добавление задач
- Удаление задач (адаптивная кнопка: "Удалить" на ПК, ✕ на мобильных)
- Отметка о выполнении
- Сохранение в localStorage
- Подсчёт статистики
- **Авторизация** (регистрация и вход по email)
- **Персональные списки задач** для каждого пользователя
- **Адаптивный дизайн** для всех устройств

---

## Технологии

- HTML
- CSS (Flexbox, анимации, медиа-запросы)
- JavaScript (ES6+, классы, querySelector)
- localStorage
