# To-Do лист

Приложение для управления задачами с сохранением в localStorage.

**Сайт:** [list-to-do-task.netlify.app](https://list-to-do-task.netlify.app)

---

## Функционал

- Добавление задач
- Удаление задач
- Отметка о выполнении
- Сохранение в localStorage
- Подсчёт статистики

---

## Технологии

- HTML
- CSS (Flexbox, анимации)
- JavaScript (ES6+)
- localStorage
